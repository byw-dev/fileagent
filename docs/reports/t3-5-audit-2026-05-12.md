## 3. 高风险逻辑核对

### 3.1 `append_mode` 默认值

- **DB 默认值**：`'overwrite'`（`000001_init_schema.up.sql:114`）✅  
- **Agent 常量**：`AppendModeOverwrite = "overwrite"`（`watcher.go:45`）✅  
- **CP handler 默认值**：`if appendMode == "" { appendMode = "overwrite" }`（`agents.go:563–566`）✅  
- **结论**：✅ 三端一致，`'none'` 已不存在

### 3.2 `mode` 大小写归一化

- **CP 写入**：`mode := strings.ToLower(req.Mode)`（`agents.go:567`）✅  
- **CP 响应**：`Mode: string(r.Mode)` 返回 lowercase（`"watch"/"scheduled"`）  
- **WebUI 发送**：`'WATCH'`/`'SCHEDULED'`（大写）  
- **WebUI TS 类型**：`CollectionMode = 'WATCH' | 'SCHEDULED'`（仅接受大写）  
- **结论**：⚠️ **P2**：创建流程（发大写→存小写）正常；但响应返回小写不符合 TS 类型，回显时存在类型不安全。不影响运行时功能（display-only），列为 P2。

### 3.3 `bucket_id → upload_bucket` 转换

- `dispatch.go:lookupBucketName`：查询 `buckets` 表获取 MinIO bucket name ✅  
- `dispatch.go:ruleToProto`：`UploadBucket: bucketName`（`dispatch.go:177`）✅  
- `DispatchRule`、`SyncRulesOnConnect` 均调用此路径 ✅  
- **结论**：✅ 稳定执行，下发链路完整

### 3.4 `enabled`/`is_active`/`status` 映射

- **创建**：`req.Enabled == nil || *req.Enabled == true` → `status = 'active'`；`*req.Enabled == false` → `status = 'inactive'`（`agents.go:568–571`）✅  
- **回显**：`Enabled: r.Status == db.RuleStatusActive`（`agents.go:470–471`）✅  
- **proto 下发**：`Enabled: rule.Status == db.RuleStatusActive`（`dispatch.go:182`）✅  
- **结论**：✅ 双向一致
